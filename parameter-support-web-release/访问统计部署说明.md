# 访问统计部署说明

统计口径：每次打开或刷新网页记 1 次 PV。数据库每天保存一行；“今日访问”是当天这一行，“累计访问”是所有日期访问量之和。接口固定使用北京时间（UTC+8）划分日期。点击“累计访问”并输入管理密码，可查看最近 100 条访问时间、IP、IP 归属地和设备信息（设备类型、操作系统、浏览器）。

## 1. 初始化 MySQL

使用 phpStudy 的数据库管理工具导入 `visit-counter-install.sql`，或在 Windows CMD 中执行：

```bat
"C:\phpstudy_pro\Extensions\MySQL5.7.26\bin\mysql.exe" -u root -p < "网站根目录\visit-counter-install.sql"
```

执行前，将 SQL 文件中的 `REPLACE_WITH_A_STRONG_PASSWORD` 替换为一个新的强密码。

## 2. 配置 PHP

在网站目录之外创建：

```text
D:\visit-counter-private
```

复制 `visit-counter-config.php.example` 到该目录，重命名为：

```text
D:\visit-counter-private\visit-counter-config.php
```

把其中的 `REPLACE_WITH_A_STRONG_PASSWORD` 替换为与 SQL 文件相同的密码。把 `REPLACE_WITH_A_DIFFERENT_ADMIN_PASSWORD` 替换成另一个密码，用于网页中打开访问明细。两个密码不要相同。数据库仅监听本机即可，不要向公网开放 3306 端口。

确认 PHP 已启用 `PDO` 和 `pdo_mysql` 扩展。

## 3. 上传文件

将以下文件放进当前网页的网站目录：

```text
index.html                    当前参数查询网页（上传时可将 parameter-support-browser.html 改名）
visit-counter.php             访问统计接口
visit-details.php             带密码验证的访问明细接口
```

数据库配置文件必须放在 `D:\visit-counter-private\visit-counter-config.php`，不要放在公网网站目录中。

`visit-counter-install.sql` 和 `.example` 文件不需要留在公网网站目录中。

## 4. 验证

打开或刷新网页后，标题栏中间应显示“今日访问”和“累计访问”。还可以访问数据库检查每日记录：

```sql
USE parameter_support_stats;
SELECT visit_date, views FROM page_views ORDER BY visit_date DESC;
```

如果网页显示 `—`，检查 Apache/PHP 错误日志，并确认 PHP 的 `pdo_mysql` 扩展、数据库密码和 MySQL 服务状态。

## 已经安装过 V0.0.5 时升级

1. 使用 MySQL 管理员执行 `visit-counter-upgrade-v0.0.6.sql`，新增访问明细和 IP 归属地缓存表并补充数据库权限。
2. 在 `D:\visit-counter-private\visit-counter-config.php` 末尾增加：

```php
define('VISIT_ADMIN_PASSWORD', '用于查看明细的新密码');
```

3. 用 V0.0.6 的 `index.html`、`visit-counter.php` 替换旧文件，并新增上传 `visit-details.php`。
4. PHP 需要启用 `curl` 扩展且服务器需要能访问外网，才能查询公网 IP 的归属地；未启用或外网请求失败时访问计数仍正常，但归属地显示“未知”。V0.0.7 起“未知”不会缓存30天，后续查询成功时会自动修复同一IP此前的未知记录。

如果旧版本已经把“未知”写入缓存，升级后用 MySQL 管理员执行一次：

```sql
USE parameter_support_stats;
DELETE FROM ip_location_cache WHERE location = '未知';
```

IP 归属地使用公网查询服务，仅能反映国家、省市和运营商的大致信息。请勿公开管理密码，并根据需要定期清理访问明细。

## V0.0.8 设备信息升级

已安装 V0.0.6/V0.0.7 时，使用 MySQL 管理员执行：

```sql
USE parameter_support_stats;
ALTER TABLE visit_details
  ADD COLUMN device_info VARCHAR(255) NOT NULL DEFAULT '未知设备' AFTER location;
```

然后替换 `index.html`、`visit-counter.php` 和 `visit-details.php`。历史记录显示“未知设备”，新访问会自动记录“电脑/手机/平板 · 操作系统 · 浏览器”。浏览器不会向网页提供电脑主机名、Windows 登录用户名或用户自定义的手机名称。
