# JT808 车辆监控平台（jt808_tracker）

一个能真的接设备、真的在地图上看位置的 808 平台网站。
设备把服务器地址指过来，位置就实时画在高德地图上，同时用电子围栏判断它在圈内还是圈外。

只依赖 Python 标准库，不用装任何第三方包。

---

## 一、启动

```bash
cd tools/jt808_tracker
python server.py
```

启动后控制台会打印两个地址，浏览器也会自动打开：

```
网页 http://127.0.0.1:8088/
  局域网访问 http://10.85.20.124:8088/
  设备服务器地址填 10.85.20.124:7611
```

常用参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `--web 8088` | 网页端口 | 8088 |
| `--tcp 7611` | 设备接入（JT808 服务端）端口 | 7611 |
| `--tcp 0` | 只起网页，不开设备口（纯看围栏用） | — |
| `--no-browser` | 不自动开浏览器 | — |

页面右上角「设备地址」显示的就是这句话里那个 `IP:端口`，照着填到设备里即可。

## 二、让设备连上来

设备侧只需要改服务器地址：

- **IP**：跑本工具的这台电脑的局域网 IP（页面右上角能看到，如 `10.85.20.124`）
- **端口**：`7611`
- 协议：JT/T 808（2013 / 2019 都行，位置汇报走 0x0200）

电脑和设备的网络要互通。如果设备在 4G 网、电脑在公司内网，需要把 7611 映射到公网，或者
让设备走 VPN —— 这一步跟工具无关。

### 已支持的报文

| 消息 | 方向 | 处理 |
|---|---|---|
| `0x0100` 终端注册 | 设备 → 平台 | 解析省域/市域/终端ID/车牌，应答 `0x8100`（结果 0 = 成功） |
| `0x0002` 心跳 | 设备 → 平台 | 应答 `0x8001`，刷新在线时间 |
| `0x0200` 位置汇报 | 设备 → 平台 | 解析经纬度/速度/方向/时间/里程，应答 `0x8001`，刷新地图与围栏判定 |
| `0x0001` 终端应答 | 设备 → 平台 | **打印下行指令的执行结果**（成功/失败/消息有误/不支持），这是判断设置是否生效的唯一依据 |
| `0x0104` 查询终端参数应答 | 设备 → 平台 | 把设备当前参数值逐条打进日志（参数 ID + 中文名 + 值） |

坐标口径：**平台内部一律用 WGS84 存储和判定**，只在贴到高德底图（GCJ-02）前做一次转换。
不转换的话设备和围栏会整体偏 300~600 米，看着像「车开进楼里了」。

## 三、画围栏

进「实时监控」→ 右侧「围栏」页签 → 点「圆形 / 矩形 / 多边形」，然后在地图上画：

| 形状 | 操作 |
|---|---|
| 圆形 | 在地图上按下鼠标，拖出半径，松手即成 |
| 矩形 | 按下鼠标拖到对角，松手即成（自动归一化，倒着拖也认） |
| 多边形 | 逐点点击，双击（或再点一次「多边形」按钮、按 ESC）收尾 |

**可以连续画多个**，画完一个不用切模式，接着画下一个即可。

每个围栏在地图中心都有一个**常显的序号徽章**（1、2、3…），和右侧列表的序号严格对应，
一眼就能看出「地图上这个圈是列表里的第几个」。

### 选中与删除

- 点地图上的围栏图形，或点右侧列表项 → 该围栏变琥珀色高亮、徽章同步变橙、地图自动定位过去
- 列表项右侧「删」按钮 → 删掉这一个
- 底部「清空全部围栏」 → 一次性清空（会二次确认）
- 「改名」按钮可以给围栏起名字，比如「厂区」「仓库」

围栏存在 `fences.json`，重启不丢。

## 四、平台指令：参数 / 围栏 / 终端控制

这三块是**平台主动下发**，和离线工具的组包逻辑完全一致（共用 `js/jt808_codec.js`），
区别是这里生成的报文可以直接点「直接下发到设备」，真的发到设备的 TCP 连接上。

### 4.1 参数管理（0x8103 / 0x8104 / 0x8106）

左栏是参数表，勾选要下发的项、填值；右栏选目标设备后自动生成报文。

| 操作 | 说明 |
|---|---|
| `0x8103` 设置终端参数 | 勾选项 + 值一起下发；不勾就不发 |
| `0x8106` 查询指定参数 | 只勾 ID，不填值（输入框会置灰） |
| `0x8104` 查询全部参数 | 消息体为空；设备回 `0x0104`，参数值直接打进日志 |

参数表与固件 `gsw_modem_validate_set_param_item()` 逐条对齐，**固件一次最多解析 9 项**
（`JT808_PARAM_ITEM_MAX`），超过会在下方直接报错。

快捷填：「服务器快捷填」一次填好 `0x0013` 地址 + `0x0018` 端口。
`0x0013` **不能带端口**（写 `1.2.3.4:7611` 会报错），端口必须走 `0x0018`。

中文车牌按 GBK 编码，也可以写 `hex:CBD5413132333435` 直接给字节。

### 4.2 围栏下发（0x8600 ~ 0x8605）

⚠️ 这块和「围栏管理」里的地图围栏是**两套东西**：

- **围栏管理**：画在本平台上，用来判定设备在不在里面，只在平台侧生效
- **围栏下发**：把围栏写进**设备里**，让设备自己报警（进出区域报警、限速）

| 消息 | 说明 |
|---|---|
| `0x8600` / `0x8602` | 设置圆/矩形，带「操作」前缀（0 更新 / 1 追加 / 2 修改） |
| `0x8604` | 设置多边形，**无操作前缀**，单条 |
| `0x8601` / `0x8603` / `0x8605` | 删除，`数量 0` = 删全部同类 |

区域属性位：bit0 起止时间、bit1 限速、bit3 进区域报警、bit5 出区域报警。
勾了 bit0 必须给合法 12 位 BCD 时间（`YYMMDDhhmmss`），写成 12 位年月日时分
会让月份变成 26 而被设备拒绝 —— 页面会在时间框下方实时回显实际要发走的 BCD，一眼能看出错。

**「取地图第 1 个围栏」**按钮可以把已经画好的地图围栏一键带进表单，省得手抄经纬度。

### 4.3 终端控制（0x8105）

| 命令字 | 含义 | 命令参数 |
|---|---|---|
| 2 | 连接指定服务器 | 9 个字段，半角 `;` 分隔，见页面下方格式说明 |
| 3 / 4 / 5 | 关机 / 复位 / 恢复出厂 | 无 |

命令字 2 的 9 个字段：`连接控制;平台鉴权码;拨号点名称;拨号用户名;拨号密码;地址;TCP端口;UDP端口;连接到指定服务器时限`
—— 无值的字段留空但**分隔符必须保留**，UDP 端口固定留空。

### 4.4 报文解析

「报文解析」视图可以贴任何上行报文：

- 支持多帧（自动按 `7E…7E` 切开，一条一条解析）
- 支持带日志前缀（`[11:02:33.441] RX <- 7E ...` 也能认出来）
- 支持有空格 / 无空格
- 每条帧给 **JSON** 和 **表格** 两种视图
- 50 种消息类型全覆盖：`0x0200` 位置含 TLV 附加项（里程/油量/SOC/信号/卫星数/进出区域…）、
  参数应答、围栏报文、多媒体、CAN、透传、RSA 等

「解析最近一条上行」可直接把刚下发过的报文拉回来核对。

## 五、判断设备在不在围栏里

每收到一条位置汇报，平台会对**每个围栏逐个判定**，结果显示在三个地方：

1. 右侧设备列表：`围栏内 2` 这种角标
2. 设备详情浮层：逐个列出「围栏内 / 围栏外」和距离
3. 地图上：即时的位置点与轨迹

判定规则：

- 圆形：到圆心距离 ≤ 半径
- 矩形：经纬度落在包围盒内
- 多边形：射线法（支持凹多边形）

## 六、地图说明

底图分两层，自动按缩放级别切换：

| 缩放级别 | 底图 | 说明 |
|---|---|---|
| 1 ~ 3 | Esri 全球图 | 能缩到看见整个世界，鼠标滚轮可缩放 |
| 4 ~ 18 | 高德矢量路网 | 国内街道最全 |

「世界视图」按钮一键缩到全球范围。**需要能访问外网**（`server.arcgisonline.com`、
`webrd0x.is.autonavi.com`）；断网时地图区会提示瓦片加载失败，但围栏和判定逻辑仍然能用。

## 七、自测（没有真设备时）

内置一个设备模拟器，走的是和真机一模一样的 808 报文：

```bash
# 单点上报一次（注册 + 一个位置）
python sim_device.py --once

# 绕圈跑，每秒一个点，用来观察围栏进出
python sim_device.py --route circle --radius 180 --interval 1.2

# 指定起点
python sim_device.py --lat 31.230416 --lon 121.473701
```

模拟器会打印自己的手机号（默认 `138001380000`，车牌 `苏A12345`），
在页面上看到这台"设备"就说明链路通了。

## 八、排查

| 现象 | 原因与处理 |
|---|---|
| 页面一直显示「还没有设备接入」 | 设备没连上 7611。先确认设备填的 IP 是**这台电脑**的局域网 IP（不是 127.0.0.1），再确认防火墙放行 7611 |
| 设备显示离线 | 超过 300 秒没收到心跳/位置；或连接已断开（断开时会立刻标离线） |
| 位置画在楼里、跟路边偏了几百米 | 设备上报的是 WGS84 还是 GCJ-02 搞混了。本平台按 WGS84 处理，若设备给的是 GCJ 需要改 `GCJ.wgs2gcj` 调用处 |
| 地图空白、瓦片加载失败 | 这台机器访问不了外网。围栏绘制与判定不受影响，只是没底图 |
| 改了 `index.html` 但页面没变 | 本服务对页面做了 mtime 缓存，改完**刷新浏览器**即可，不用重启（重启会断掉设备连接） |
| 端口被占用 | `python server.py --web 9000 --tcp 7612` 换一组端口 |

日志在控制台实时打印，页面上「报文日志」视图也能看最近 200 条。

## 九、文件清单

| 文件 | 作用 |
|---|---|
| `server.py` | 全部后端：808 编解码、TCP 服务端、HTTP + REST、围栏判定、持久化、主动下发 |
| `index.html` | 平台前端（平台布局 + 地图 + 四个指令视图） |
| `../shared/jt808_codec.js` | 组包：0x8103/0x8104/0x8106 / 0x8105 / 0x8600~0x8605，含 GBK 编码与 BCD 校验 |
| `../shared/jt808_parser.js` | 反解：50 种消息体、多帧切分、TLV 附加项 |
| `vendor/` | Leaflet 1.9.4（本地化，内网部署不依赖 CDN） |
| `assets/` | 地图图标 |
| `sim_device.py` | 设备模拟器 |
| `fences.json` | 围栏持久化（自动生成） |

### 编解码只有一份

`tools/shared/jt808_codec.js` 和 `tools/shared/jt808_parser.js` 是**全项目唯一一份**，
本平台通过 `/js/xxx.js` 引用（`server.py` 把它映射到 `../shared/`），
离线工具 `jt808_offline` 通过 `../shared/xxx.js` 引用同一份文件。

改协议只需要改 `shared/` 一处，两个工具同时生效。两边算出来的报文逐字节一致，
可以互相核对 —— 这是把两份代码合并后的直接收益。

## 十、REST 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 全部状态：围栏、设备、轨迹、围栏判定、日志 |
| GET | `/api/config` | `{tcp_port, web_port, lan_ip}` |
| POST | `/api/fence/save` | 保存/更新围栏（带 `id` 则更新，不带则新建） |
| POST | `/api/fence/delete` | `{id}` 删除单个 |
| POST | `/api/fence/clear` | 清空全部 |
| POST | `/api/send` | **平台主动下发**：`{phone, hex, msg_id, msg_name}`，`hex` 为含 `7E` 的完整帧 |

`/api/send` 返回：

- `200 {ok:true, message:"已下发 62 字节"}` — 已写到设备连接上
- `409 {ok:false, message:"设备 xxx 当前不在线（没有活动 TCP 连接）"}` — 设备没连
- `400 {ok:false, message:"报文必须以 7E 开头结尾"}` — 帧格式不对

注意：`200` 只代表**字节已经发出去**，不代表设备执行成功。设备执行结果要通过
`0x0001` 应答回来看（平台会把它打进日志：「应答 8103 设置终端参数 <- 流水号 1：成功/确认」）。

围栏请求体示例：

```json
{ "shape": "circle",  "points": [[31.230416, 121.473701]], "radius": 300 }
{ "shape": "rect",    "points": [[31.228, 121.470], [31.233, 121.477]] }
{ "shape": "polygon", "points": [[31.228,121.470], [31.228,121.478], [31.234,121.474]] }
```

`points` 里一律是 `[纬度, 经度]`，WGS84。
