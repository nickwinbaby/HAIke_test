# GNSS 综合工具箱

本工程是一个独立运行的 Tkinter 桌面工具。所有功能的实现代码均位于本工程内，运行时不会导入、启动或调用 `GPS_COLL` 目录中的旧脚本。

## 已整合功能

| 功能页 | 工程内实现模块 |
| --- | --- |
| 坐标转换 | `core/coordinate.py` |
| Excel → KML | `core/excel_kml.py` |
| TXT → KML | `core/nmea_kml.py` |
| CEP 分析 | `core/cep.py` |
| 冷热启动 | `core/cold_start.py` |
| 电子围栏绘制与 KML | `core/fence_kml.py`、`core/map_picker.py`、`map/` |
| 4.0 / JT/T 808 电子围栏组包 | `core/fence_packet.py`、`ui/panels.py` |
| 地图经纬度标记 | `core/fence_kml.py`、`core/map_picker.py`、`map/` |
| KML 轨迹查看 | `core/map_picker.py`、`map/` |

`ublox原始NEMA数据定位时间差统计.py` 按要求未整合。

## 启动

双击 `启动GPS综合工具箱.bat`，或在本目录执行：

```powershell
python main.py
```

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## 功能规则

- 坐标转换支持 WGS84 ↔ GCJ-02、WGS84 ↔ BD-09，并支持度分秒/度分批量转 WGS84 十进制度；多个值使用逗号分隔。
- Excel → KML 默认使用“4.0 工具导出的 GPS 数据”；也可选“仅经纬度数据”，经度、纬度为必需列，备注列可选。
- NMEA 的 GGA/RMC 正则、经纬度换算、轨迹/点位内容和时间戳命名保持不变。
- CEP 的过滤、距离、百分位取值方式、图片、卫星数 Excel 和命名保持不变。
- 冷热启动的时间戳格式、启动分段、有效定位判定和统计文案保持不变。
- Excel → KML、TXT → KML 和 CEP 分析均不预设输出目录，生成或分析前由用户选择。

## 电子围栏绘制

- “电子围栏绘制”页可手工输入圆形、矩形或多边形参数并生成 KML。
- 电子围栏地图只提供圆形拖拽、矩形拖拽和多边形逐点绘制。
- 地图一次只保留一个围栏；重新绘制圆形、矩形或多边形会直接替换原围栏，确保回填目标唯一。

## 地图经纬度标记

- “地图经纬度标记”是独立功能，只负责在地图上连续选点并标注经纬度。
- 每个标注点使用带序号的蓝色地图图钉，并显示对应的纬度、经度标签。
- “定位当前位置”通过浏览器调用 Windows 定位服务，自动跳转并显示当前位置和精度范围。
- 标注点回填后可查看 WGS84 坐标列表，并单独导出点位 KML。

## KML 轨迹查看

- “轨迹查看”位于“地图标点”和“坐标转换”之间。
- 地图页面可同时导入多个本机 KML 文件，支持 LineString、Point、Polygon 和 gx:Track。
- KML 文件只在本机浏览器中读取，不会上传；KML 的 WGS84 坐标会转换后匹配高德底图显示。
- 已导入文件显示在地图左侧，可逐个显示、隐藏或删除，也可确认后删除全部轨迹。
- KML 点位以彩色图钉显示；点击图钉可查看点位名称、备注和 WGS84 经纬度。
- 文件名前的颜色圆点可点击换色，轨迹线、多边形和图钉会同步更新；没有名称的点位不显示悬停标题。
- “显示名称”开关默认关闭；关闭时鼠标悬停显示 KML 名称，开启后名称常驻地图，并可选择 14/12/10/8/6 px 字号（默认 12 px）。
- 当前工具进程运行期间，导入文件、显示状态和自定义颜色保存在本机服务中，刷新地图页面会自动恢复。
- 在轨迹地图中搜索 WGS84 `纬度,经度` 时，会自动生成以坐标命名的搜索标记，并加入左侧列表，可定位、换色、隐藏或删除，刷新后仍会恢复。

## 地图说明

- 地图默认中心固定为 WGS84 `34.188178, 108.878631`；显示到高德底图前自动转换为 GCJ-02。
- “显示所有标记点”会自动平移、缩放，使当前全部标注点或围栏进入可视范围，不会修改坐标。
- 地图显示使用高德/Esri 在线瓦片；地点搜索使用 Photon，因此地图功能需要外网。
- 地图工具栏可在高德“详细”“简洁”和“卫星影像”瓦片样式间切换；卫星影像不叠加道路标注层，可用于减少商户文字干扰。
- 地图显示时处理 GCJ-02 偏移，回填、KML 和数据保存统一使用 WGS84。
- 首次读取当前位置时，浏览器会请求位置权限；需要允许该权限，并确保 Windows 定位服务可用。
- 地图、本地服务和围栏逻辑均位于 `gps_tools_all`，运行时不访问 JT808 工具目录。

## 小窗口显示

- 所有功能页均带独立纵向滚动条，并支持鼠标滚轮。
- 主窗口最小尺寸为 `760 × 480`；缩小后可滚动查看被折叠到下方的参数和按钮。

界面允许临时更改输出目录。CEP 分析遇到非 UTF-8 输入文件时，会把该文件转换为 UTF-8 后再分析。
