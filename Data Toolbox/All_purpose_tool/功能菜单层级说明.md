# 数据分析综合工具箱功能一览

```text
数据分析综合工具箱
├─ GNSS工具
│  ├─ KML生成
│  │  ├─ TXT → KML
│  │  │  └─ 支持的内容
│  │  │     • 从 TXT/NMEA 的 GGA、RMC 语句读取定位数据
│  │  │     • 生成轨迹 KML 和点位 KML
│  │  └─ Excel → KML
│  │     └─ 支持的内容
│  │        • 读取 4.0 工具 3.1 章节导出的 Excel
│  │        • 读取仅经纬度的 Excel，经度、纬度必填，备注列可选
│  │        • 生成轨迹和点位 KML，备注可写入对应点位
│  ├─ CEP 分析
│  │  └─ 支持的内容
│  │     • 自定义锚点，计算 CEP50、CEP68、CEP95、CEP99 等定位精度指标
│  │     • 导出散点图、柱状图和可用卫星数 Excel
│  ├─ 冷热启动
│  │  └─ 支持的内容
│  │     • 按自定义启动关键字分段，统计每次启动到首次有效定位的耗时
│  │     • 可调整定位语句关键字，也可跳过 GGA 定位有效性标志检查
│  ├─ 电子围栏
│  │  ├─ 围栏绘制
│  │  │  └─ 支持的内容
│  │  │     • 手动填写或在地图绘制圆形、矩形、多边形，回填参数并导出围栏 KML
│  │  │     • 地图可独立标记参考点，参考点不参与围栏回填
│  │  ├─ 4.0 协议围栏组包
│  │  │  └─ 支持的内容
│  │  │     • 生成 F10F 设置围栏列表、删除全部、删除部分报文
│  │  │     • 设置圆形、矩形和多边形围栏，保留 11 点多边形用于超协议测试
│  │  │     • 复制组包结果，可通过数据发送区提交 IMEI 和 CMD
│  │  └─ 808 协议围栏组包
│  │     └─ 支持的内容
│  │        • 按 JT/T 808-2013 设置或删除圆形、矩形、多边形围栏
│  │        • 手动输入或地图绘制回填，生成并复制完整帧
│  │        • 在数据发送区编辑 IMEI 和 CMD 后发送
│  ├─ 地图标点
│  │  └─ 支持的内容
│  │     • 地图连续标点，定位当前位置，回填 WGS84 经纬度
│  │     • 查看「纬度,经度」列表，导出标注点 KML
│  ├─ 轨迹查看
│  │  └─ 支持的内容
│  │     • 导入多个 KML，查看轨迹、点位、多边形和点位备注
│  │     • 管理轨迹和坐标搜索标记，可显示、隐藏或删除
│  │     • 调整图钉颜色、点名显示和字号，切换详细、简洁或卫星底图
│  └─ 坐标转换
│     └─ 支持的内容
│        • WGS84 ↔ GCJ-02、WGS84 ↔ BD-09 双向转换
│        • 度分秒或度分转十进制度，支持多个值以逗号分隔
├─ 数据处理
│  ├─ 数据转换
│  │  ├─ HEX / ASCII
│  │  │  └─ 支持的内容
│  │  │     • HEX 字节与 ASCII 文本双向转换，可粘贴多行内容
│  │  └─ 时间转换
│  │     └─ 支持的内容
│  │        • Unix 或 HEX 时间戳转北京时间，支持自动识别秒或毫秒
│  │        • 北京时间转 Unix，可选择输出秒或毫秒
│  │        • 查看并复制当前北京时间和 Unix 秒级时间戳
│  └─ 数据加解密
│     └─ 支持的内容
│        • 本地 AES 加密和解密，支持 CBC、ECB 以及 128/192/256 位密钥
│        • 支持 PKCS7、Zeros、None 填充，密钥和 IV 可用 Text 或 Hex
│        • 明文支持 UTF-8 或 Hex，密文支持 Base64 或 Hex
├─ 文件对比
│  └─ 支持的内容
│     • 对比纯文本、DOCX 正文与表格、二进制文件
│     • 二进制结果显示十六进制偏移、字节和对应的 ASCII
│     • 文件夹按相对路径、项目类型、文件大小和修改时间对比
│     • 独立窗口可切换全部、仅差异或仅相同，支持目录展开和折叠
│     • 支持手动刷新、每 5 秒自动刷新（最长 30 分钟）和 Windows 右键对比
└─ 哈希算法
   └─ 支持的内容
      • 选择或拖入文件、文件夹，逐个文件计算校验值
      • 粘贴文本，按 UTF-8、GBK、GB18030、UTF-16LE 或 UTF-16BE 编码计算
      • 可多选 MD5、SHA-1、SHA-256、CRC-32、CRC-32-RL，默认勾选 MD5
      • CRC-32-RL 计算配置行的校验值，去掉行尾展示用的反斜杠，每行以 LF 结束
      • 支持复制和保存结果
```
