# 自动化测试第一版

这个文件夹先把你给的 9 个步骤做成一个可运行的 Python 自动化流程。

## 当前流程

1. 搜索并连接程控电源 USB 串口。
2. 程控电源设置到 12V，并打开输出。
3. 等待 60 秒。
4. 程控电源从 12V 逐步升到 14.5V，默认 20 步，2 秒内完成。
5. CAN 模拟开始工作。
6. CAN 持续工作 2 分钟。
7. CAN 停止工作。
8. 程控电源从 14.5V 逐步降到 12V，默认 20 步，2 秒内完成。
9. 等待 60 秒。
10. 程控电源设置 0V，并关闭输出。

## 先做快速空跑

```powershell
python .\自动化测试\run_case.py --dry-run --time-scale 0.01
```

## 真实执行硬件

```powershell
python .\自动化测试\run_case.py
```

## 单步确认模式

每执行完一步后按 Enter 执行下一步：

```powershell
python .\自动化测试\run_case.py --manual
```

## 配置文件

当前用例在：

```text
自动化测试/case_voltage_can.json
```

后续新增业务场景时，复制这个 JSON 改步骤即可。底层驱动代码集中在 `automation/` 目录里，后面可以继续接入继电器、服务器接口、MQTT、数据校验规则和报告生成。
