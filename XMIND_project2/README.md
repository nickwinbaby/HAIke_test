# GNN

一个基于 Python 3.10、FastAPI、WebSocket 和 SQLite 的本地协作思维导图编辑器。它适合在同一台电脑或可信局域网里多人同时编辑，不依赖 XMind 客户端。

## 快速启动

要求：Python 3.10+（安装时保留 Tcl/Tk）、Node.js 18+（首次构建前端时需要）。

Windows 下双击 **`start.vbs`**，打开原生服务管理窗口，全程不保留命令行。双击 **`start.bat`** 也会打开相同窗口，启动时可能短暂闪现命令行。界面提供：

- **启动服务 / 停止服务**：后台启动，正常停止会等待当前请求结束，保存过的导图不受影响。
- **打开导图**：浏览器访问编辑器；关闭浏览器不会停止服务。
- **运行日志 / 打开日志 / 打开数据目录**：日志保存在 `data/launcher.log`，自动轮转，避免无限增长。
- **端口 / 允许局域网访问**：启动前设置；运行中修改需要先停止服务。
- **退出确认**：服务运行时关闭管理窗口会询问是否停止；取消则继续运行。窗口异常退出时，受控服务也会尝试自动结束，避免遗留后台进程。

首次启动会自动创建 `.venv`、检查 Python 运行依赖，缺失时才安装；已有前端构建文件时不需要 Node。重复双击只会唤起同一个管理窗口。如果检测到旧命令行启动的同一工作空间，先显示“已有服务”，不会自行中断；点击 **接管旧服务** 并确认后，核实数据库路径、监听进程及进程创建时间，再结束旧服务并重新启动。接管旧版进程不是平滑停止，协作者会短暂断线；之后即可在 GUI 中正常启停。其他程序占用端口时只会提示，不会结束它们。

检测到已有服务或端口占用时，“启动服务”会禁用，避免重复启动和日志刷屏。窗口每 3 秒刷新一次这两种状态；原服务退出或端口释放后，会自动恢复启动按钮。状态不变时不会重复打印提示，刷新也不会自动接管或重启服务。

如果停止失败，窗口会保留对子进程的管理并显示“重试停止”，不会误报已停止或允许重复启动；关闭窗口时遇到同类问题也会保持窗口打开。进程确认退出后，才恢复启动按钮或完成退出。端口输入中的前导零、首尾空格按同一个实际端口识别。

也可以从 PowerShell 打开 GUI：

```powershell
.\start.ps1
```

默认编辑器地址为 <http://127.0.0.1:8765>。GUI 不会修改导图的存储方式，也不会修改原 XMind 文件。

要让同一局域网的其他电脑访问：

```powershell
.\start.ps1 -Lan
```

也可在窗口中勾选“允许局域网访问”。启动后窗口及日志会显示本机 IPv4 访问地址，其他电脑用 `http://本机局域网IP:8765` 访问；需要本机防火墙允许该端口。当前版本没有账号、权限和 HTTPS，局域网模式只能用于可信网络，不要直接暴露到公网。

保留命令行模式用于排查问题：`.\start.ps1 -Console`（可加 `-Port 8766`、`-Lan`）。正常使用直接双击 `start.vbs` 即可。

## 开发命令

```powershell
# 安装前端依赖并构建
npm ci
npm run build

# 运行 Python 测试
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 自动启动隔离测试服务，运行双窗口协同测试（不会修改正式数据库）
npm run test:ui

# 节点层级标识、分支视图与双窗口协作回归
node test-branch-view-ui.mjs
```

## 当前功能

- 子主题、同级主题、插入父主题、双击/F2 就地编辑、删除、折叠、排序和拖动改层级
- 思维导图、左右逻辑图、上下组织结构图；六套主题、背景、间距及三种分支线
- 节点形状、字号、粗斜体、自定义颜色、优先级、任务进度、标签、超链接和图片
- 关系线、边界、概要、大纲、全文搜索、右键菜单及分支复制粘贴
- 选中节点时标识祖先与后代；仅看当前分支、层级路径导航与独立查看范围
- WebSocket 实时同步、在线人数、同字段并发冲突保护
- 每次打开或刷新先填写姓名，在线协作者和后续历史版本使用该姓名标记
- 本地 SQLite 持久化，最近 3,000 个历史版本可追溯操作者和修改内容，并可打开为副本
- 导入旧版/新版 XMind 和 JSON；导出 XMind、JSON、Markdown、PNG、SVG
- Ctrl+Z 撤销、Ctrl+Shift+Z/Ctrl+Y 重做；画布平移缩放和浏览器草稿保留

每位协作者独立控制自己的缩放和画布位置，视角不参与协作同步。拖动画布空白处可自由平移，普通滚轮上下移动画布，按住 Ctrl（macOS 为 Command）再滚轮才缩放。添加子主题或同级主题保留当前缩放；新节点超出屏幕时，仅在操作者自己的画布中平移到可见区域。改变窗口大小或开关侧栏会保留缩放和视野中心。每张导图的视角保存在当前浏览器，刷新或重新打开时恢复；首次打开和主动点击“适应全图”时才按全图调整视角（主动切换布局、展开全部也会适应全图）。同一浏览器的多个已打开页面各自操作，重新打开时读取该浏览器最后保存的视角；当前没有账号登录体系。

选中分支节点时，当前节点显示紫色实线，沿途祖先显示橙色实线，其全部后代显示蓝色虚线，对应连接线也会加亮。切换选择后标识跟随改变，节点原有颜色和样式不会被改写。这些标识只在当前页面显示，其他协作者独立选择。

右键父节点选择“仅看此分支”，或在右侧“节点”详情中点击同名按钮，可只显示该节点及后代。分支视图使用原导图的真实节点，添加、编辑、删除和撤销仍写入原导图并实时同步；进入或退出视图本身不产生历史版本。顶部路径可跳转祖先，支持继续进入更深分支；“返回上层”恢复上次视图，“返回全图”恢复进入分支前的全图位置与缩放。每个页面的查看范围独立，刷新后回到全图；搜索全图中当前范围之外的节点会退出分支视图。如果协作者删除当前分支，则自动回到仍存在的上级分支或全图。JSON、XMind、Markdown 仍导出完整导图；PNG、SVG 按当前分支和展开状态导出。

每次打开或刷新页面都必须填写显示姓名，姓名在当前页面内固定，并用于在线成员和之后产生的历史记录。系统会拒绝空姓名、纯数字和“访客/匿名”等占位名称，但当前没有账号认证，无法证明填写者就是姓名本人；这项功能用于可信团队内的记录追溯，不等同于身份认证或权限控制。升级前已经生成的历史作者名称保持原样。

节点删除确认每次打开或刷新页面只需确认一次；取消不会免除下次提示。确认后，同一页面内通过工具栏、Delete 键或右键菜单删除节点均不再弹窗，切换导图也不会重复提示。其他协作者和其他页面独立确认；误删节点可用 Ctrl+Z 撤销。

“全部导图”是数据库中保存的导图副本，不是缓存。每张导图右侧的垃圾桶按钮可以删除整张导图，每次均需确认；这会删除该副本的全部历史和撤销记录，不能用 Ctrl+Z 恢复，也会让正在查看它的协作者退出该导图。原始 XMind 文件不受影响，需要保留修改内容请先导出。确认期间发生协作修改会拒绝删除，需要重新查看并确认。删除最后一张后工作空间保持为空，重启不会重新创建示例。

## 保存位置

已提交的内容自动保存在本目录的 `data/mindcollab.sqlite3`。导入 XMind 时会在数据库中创建协作副本，不会修改或覆盖原 `.xmind` 文件；其他电脑通过局域网协作时，内容也保存在运行服务的这台电脑。

需要独立文件备份时优先使用“导出 → JSON”或 XMind。需要迁移整个工作空间时，先停止服务，再复制 `data` 文件夹。右侧详情中尚未点击保存的草稿只存在当前浏览器。

## 当前边界

- 单进程服务，适合原型和小规模局域网使用；尚未加入账号、权限、审计、反向代理和多实例部署
- 不设置固定节点数量或导图层级上限；实际流畅度取决于电脑内存、CPU、浏览器和节点内容。单个导入文件、导图数据及单次协作消息上限为 128 MB，用于防止异常文件耗尽内存，不是节点数量授权限制
- XMind 导入读取全部工作表，兼容新版 content.json 与旧版 content.xml；每张工作表分别保存为一张导图，在左侧显示工作表名称并可切换编辑。导入结果显示各表名称和节点数，不设置固定工作表数量限制；全部解析成功后才一起保存，避免导入一半。长节点标题完整保留，不再截断为 200 字。可识别常见样式、布局、标签、任务标记、链接、节点图片和关系线；附件、公式、部分边界/概要及复杂主题效果不能保证还原
- 每张导入的工作表独立协作、记录历史、删除和导出；当前 XMind 导出仍只导出正在打开的这一张导图，其他工作表需分别导出。已导入的旧副本不会自动补齐，需重新导入原文件
- XMind 导出包含通用节点结构、样式、标记、图片和关系线，并内嵌 `mindcollab.json` 用于本应用无损重导入；未在所有 XMind 桌面版本上做兼容认证，JSON 仍是最稳妥的完整备份格式
- 撤销/重做栈属于当前浏览器会话。相关节点被协作者继续修改后，系统会拒绝可能覆盖他人内容的撤销；此时可用历史版本打开副本
