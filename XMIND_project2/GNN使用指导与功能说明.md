# GNN 使用指导与功能说明

## 1. 工具简介

GNN 是一款本地运行的协作思维导图工具，主要用于解决以下问题：

- 普通 XMind 文件不方便在局域网内多人同时编辑。
- 节点较多时，层级关系不容易辨认，查找和维护比较困难。
- 团队修改后难以追溯是谁修改了什么内容。
- 希望导图数据保存在自己的电脑上，而不是依赖外部云平台。
- 希望导入已有 XMind 内容后继续协作，同时不修改原始 XMind 文件。

GNN 在一台电脑上启动服务后，同一局域网中的其他人员可以通过浏览器共同编辑。所有协作者看到的是同一份导图内容，但每个人的画布位置、缩放比例、折叠状态和分支视图互不干扰。

### 主要痛点与解决方式

| 实际痛点 | GNN 的解决方式 |
| --- | --- |
| 商业软件的多人协作通常依赖账号、会员席位或厂商云服务 | 一台电脑启动服务，局域网成员使用浏览器参与协作，无需逐人安装客户端或购买协作席位 |
| 测试用例、协议流程和客户需求等内部资料不适合上传外部云端 | 导图、历史和撤销数据保存在自己的服务电脑，可在断网局域网中使用 |
| 大型技术导图节点多、层级深，定位和维护困难 | 提供祖先路径与后代标识、折叠、大纲、搜索和仅看当前分支等功能 |
| 多人修改后难以确认谁改了什么 | 历史记录保存操作者、时间和修改内容，并可将旧版本打开为副本 |
| 通用商业产品无法完全符合内部业务习惯 | 工具可继续按测试用例、协议和需求管理流程进行定制开发 |
| 导入文件后担心覆盖原始 XMind | 导入时创建本地协作副本，不修改原始 `.xmind` 文件 |

### 与 XMind、WPS 思维导图相比的优势

GNN 的优势不在于模板数量或商业化完成度，而在于以下差异化能力：

- **数据自主**：数据默认保存在自己的电脑，不依赖外部云端。
- **低成本局域网协作**：无需按协作者数量购买会员或席位，其他成员使用浏览器即可加入。
- **离线可用**：在没有互联网的可信局域网中仍可协作。
- **业务可定制**：可以根据团队的协议分析、测试用例和需求维护方式继续增加功能。
- **更重视大型技术导图维护**：层级标识、分支视图、独立画布视角和修改追溯均围绕复杂导图设计。
- **部署与分发简单**：便携版无需另外安装 Python；安全分发包不包含个人数据库和源代码。

XMind 和 WPS 在模板、主题、排版、移动端、格式兼容、账号权限及整体成熟度方面更完善。GNN 不以全面替代这些商业产品为目标，而是作为面向内部技术团队的本地协作与定制化工具。

可以将工具定位概括为：

> GNN 是一款面向内部技术团队的本地协作思维导图工具，重点解决数据不便上云、商业协作成本、复杂技术导图维护困难以及通用软件无法按业务定制的问题。

## 2. 启动与关闭

### 启动

1. 解压完整的 GNN 便携版文件夹。
2. 双击 `GNN.exe`。
3. 在服务管理窗口中点击“启动服务”。
4. 点击“打开导图”，进入浏览器编辑页面。
5. 输入真实姓名后进入工作空间。姓名会用于在线成员显示和历史记录。

### 关闭

1. 回到 GNN 服务管理窗口。
2. 点击“停止服务”。
3. 确认服务停止后再关闭窗口。

只关闭浏览器页面不会停止服务，也不会删除已保存的导图。

## 3. 基本使用方法

### 新建与导入

- 点击“新建思维导图”可以创建空白导图。
- 点击“导入 XMind / JSON”可以导入已有文件。
- 多工作表 XMind 会按工作表分别生成导图，可在左侧列表中切换。
- 导入操作只创建协作副本，不会覆盖或修改原始 `.xmind` 文件。

### 编辑节点

- 双击节点或按 `F2`：编辑节点文字。
- 按 `Tab`：添加子主题。
- 按 `Enter`：添加同级主题。
- 按 `Delete`：删除所选分支。
- `Ctrl + Z`：撤销。
- `Ctrl + Shift + Z` 或 `Ctrl + Y`：重做。
- 拖动节点到另一个节点：调整节点层级。
- 右侧“节点详情”可修改备注、颜色、形状、字号、标签、链接和任务进度等内容。

节点存在备注时，右下角会显示文本文档图标，便于快速识别。

### 画布操作

- 拖动画布空白处：自由平移画布。
- 普通滚轮：上下移动画布。
- `Ctrl + 滚轮`：放大或缩小画布。
- 点击右下角缩放按钮：手动调整缩放或适应全图。
- 父节点后的 `−` / `+`：折叠或展开该节点下的全部子节点。

### 大型导图辅助功能

- 选中节点后，当前节点、祖先路径和下属分支会使用不同颜色标识。
- 点击“分支视图”或右键选择“仅看此分支”，可以只查看和维护当前节点及其后代。
- 分支视图修改的仍然是原导图，不会生成另一份独立内容。
- 返回全图后，原有树结构和其他分支仍然保留。
- 大纲和搜索功能可用于快速定位节点。

## 4. 多人协作

1. 启动服务前开启“允许局域网访问”。
2. 启动后，将管理窗口显示的局域网地址发送给同事。
3. 同事在浏览器中打开地址，输入自己的姓名即可参与编辑。

协作过程中：

- 节点的新增、修改和删除会实时同步。
- 可以查看当前在线人员及其正在查看的节点。
- 每个人的缩放、画布位置和分支视图独立，不会互相拉动画布。
- 历史记录会保存操作者、修改时间和修改内容。

本工具目前没有正式账号、权限和身份认证，只适合在可信的公司或家庭局域网中使用，不应直接暴露到公网。

## 5. 保存、历史与恢复

- 已提交的修改会自动保存到运行服务电脑的 `data/mindcollab.sqlite3`。
- 右侧尚未点击“保存修改”的内容属于当前浏览器草稿，未必已同步给其他人。
- 历史版本可以查看修改人和修改内容，也可以将旧版本打开为副本。
- 删除的整张导图会先进入回收站，30 天内可以恢复或彻底删除。
- 导出功能支持 XMind、JSON、Markdown、PNG 和 SVG。
- JSON 适合完整备份；XMind 适合继续在 XMind 软件中编辑。

迁移或备份整个工作空间时，应先停止服务，再复制程序目录中的 `data` 文件夹。

## 6. 对外分发说明

项目生成的安全分发 ZIP 只包含运行程序和使用说明，不包含：

- `mindcollab.sqlite3` 数据库；
- 已有导图和历史记录；
- 运行日志与备份；
- Python 源代码。

接收者首次启动后，会在自己的电脑上创建新的空数据库。

不要把自己已经使用过的完整 GNN 文件夹直接压缩后发送，因为其中的 `data` 文件夹可能包含个人或项目导图。

## 7. 适用场景

GNN 适合以下场景：

- 测试用例、协议流程和需求结构设计；
- 项目功能拆解和问题分析；
- 小团队在局域网内共同维护思维导图；
- 将已有 XMind 文档转换为可协作维护的本地副本；
- 需要保留修改历史，同时希望数据由自己管理的场景。

当前版本定位为本地及小规模局域网协作工具，不替代企业级账号权限系统或公网云协作平台。
